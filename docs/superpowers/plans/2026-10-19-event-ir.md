# Event-based SignIR Implementation Plan

> For agentic workers: use superpowers:executing-plans for inline implementation,
> then a fresh whole-change review under superpowers:requesting-code-review.

**Goal:** Implement the approved local hybrid event checker and measurable evaluation.
**Architecture:** Independent model readers create validated evidence-bearing graphs.
Conservative event alignment feeds per-fact deterministic comparison and audit reports.
**Tech Stack:** Python 3.11+, Pydantic 2, SciPy, standard-library HTTP/JSON/CSV.
**Spec:** `docs/event-architecture.md`.

## Global constraints

- Preserve existing uncommitted semantic repairs and the legacy API.
- Implement on `feat/event-ir`; publish an isolated `feat/event-ir-pr` from `main`
  without earlier local repairs or research reports.
- Local model configuration is explicit; no corpus uploads/downloads or live model assumptions.
- Original text/evidence, unresolved items, and all failed rows remain visible.
- No accuracy claims without independent human judgments.

## Review focus

- Repeated indistinguishable events must not align by counts, polarity, or order.
- Conditional/reported events and parent-event ambiguity must not produce false conflicts.
- Model identity drift, truncation, malformed output, and HTTP redirects must fail visibly.
- Partial or failed batch output must not manufacture coverage or overwrite sources.
- Independent evaluation must retain UNKNOWN misses and reject mismatched IDs/text.
